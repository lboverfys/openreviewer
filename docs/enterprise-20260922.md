# 2026-09-22 深化验证与界面重构

本轮针对真实效果、Agent 成本、数据库聚合、恢复与容量四条主线补充代码；同时用 shadcn/ui
重构基础控件和页面布局。工作区基线为 `8aec195`。浏览器 MCP 按用户要求不使用，组件回归
不能替代浏览器视觉验收。

## 评测质量与成本

- 复核问题可以选择上下文缺失、推理错误、证据不匹配、定位错误、重复报告或其他原因。
  双人模式只汇总一致归因，分歧单独统计；机器引用核验不能代填人工判断。
- 干净 PR 误报率只统计正常变更中参考标签已确认且为空的配对。没有标注不代表没有缺陷。
- 每个确认缺陷的估算成本限定在双方费用已知、参考已确认的同一批配对：累计费用除以去重后的
  已知缺陷命中数。该批次中的零命中运行仍计成本；分母为零时返回未知。
- 新字段复用已有评测 JSON 和聚合 SQL，不新增表或逐样本请求。旧归因缺失保留为未分析。
  单集继续限制 200 PR / 400 观察；报告仍由单条有范围过滤的 SQL 聚合。

## 独立调用对照

`apps.maintenance.run_review_experiment` 增加 `single_generalist` 和 `without_context`：

- `single_generalist` 使用冻结方案的逻辑模型、完整变更与合并后的知识引用，取消角色输入筛选，
  采用系统综合审查要求，不执行三路汇总。仍遵守同样的分批、输出和请求预算。
- `without_context` 仅移除关联代码上下文，仓库规则、角色和模型保持一致。
- 原有 full 和逐个移除角色的对照继续支持。每个变体重新发起请求，轮换顺序、不复用审查结果。
- 报告分别汇总候选数、调用次数、已记录 Token、失败和未知用量、估算费用及模型阶段耗时。
  单路和多路消耗可能不同，不能将更多计算量的收益全部归因于角色设计。
- 人工质量继续为 null，直到真实人员完成核对。试点固定为 `pilot_not_validation`；同一 PR
  调参后不能再当作未见过的验收样本。统计耗时不包含排队、CI、冷索引或网络入口。

示例：先使用 `prepare --variants full single_generalist without_context` 固定来源，再通过
`run --budget-usd <已确认预算> --max-requests <上限>` 独立运行。旧四变体计划继续兼容。
输出必须使用新的受控目录；原文和源码不可进入 Git 或普通日志。生产默认方案不自动更换。

## PostgreSQL 性能与恢复

请求统计使用 PostgreSQL `percentile_disc` 聚合实际耗时，避免在全账本上物化两层逐行窗口。
SQLite 保留等价最近秩算法，仅用于本地功能测试。两个实现都排除未知耗时，费用和状态分母不变。
没有为此修改共享 `work_mem`、新增索引或近似计算分位数。

十万请求脚本在同一个数据库事务中交替执行原窗口算法和新算法六轮，先逐字段对账，再保存
每轮 `EXPLAIN (ANALYZE, BUFFERS)`；以对应 SHA 的 CI 产物为证据，不把历史不同硬件的数字
直接相除当作优化幅度。诊断继续固定八条查询，处理范围在数据库侧过滤，返回条数有上限。

新增真实时间恢复测试：子进程取得两秒租约后被终止，真实轮询等待过期和一秒退避，测量
终止至替代领取耗时，拒绝旧 Worker 续租。三次试验仅为缩短参数的隔离冒烟，不宣称生产 RTO。
原有 HTTP 返回后、结算前故障注入继续验证未知费用和幂等结算。

新增 1/2/4/8 个并发领取者的容量测试，每组 40 任务、四仓库、70% 热点任务，仓库并发上限二。
使用 20ms 模拟处理器，报告领取 P95、任务吞吐、空轮询、仓库最大等待及峰值并发。它测量队列
与数据库路径，不代表真实模型吞吐。保持现有短事务锁，先测量扩展边界。

## shadcn 界面

采用官方 shadcn/ui new-york 组件源码，使用 Tailwind v4、Radix Dialog/Slot、CVA 与 cn。
按钮、输入框、下拉框、表格、徽章和共享表单卡片贯穿所有管理页面。旧业务样式置于独立层，
组件与工具类有明确优先级；保留已有权限、分页、表单提交、冲突与失败处理。

截图中的复查配置从窄按钮列迁入独立弹窗；确认前不发起收费动作，单页方案隐藏无意义分页。
弹窗支持 Escape、焦点管理、禁用和滚动；提交期间阻止重复动作与关闭。
同时调整导航、列表宽度、长文本操作、数字后缀、手册滚动以及移动端布局。
验证涵盖已有各页面 DOM 流程和新增弹窗回归；本轮未做真实浏览器或所有屏幕尺寸的视觉验收。

## 本轮证据

本地复用 D 盘 Python 3.12.10 与 Node 22.19.0，新增依赖仅在项目 web/node_modules。
临时文件、构建缓存和产物均位于 D 盘约定目录的 `enterprise-20260922` 子目录。

TypeScript、Vite、Ruff、Mypy、OpenAPI、真实评测 Schema 和 24 个录制回放检查通过。
