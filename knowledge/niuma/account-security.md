## 使用方式

- 用户端、陪玩师端：点击右上角头像，再点「账号与安全」，在当前页面打开同一个弹窗。
- 客服端：侧栏新增「个人设置」，地址为 `/support/settings`。
- 三端均提供「基本资料」「修改密码」「登录设备」三个页签，支持浅色、深色和手机布局。
- 基本资料可以修改昵称、上传头像、恢复默认头像。未上传图片时，优先显示昵称首字；未设置昵称时显示邮箱首字。邮箱继续作为登录账号，不在这里修改。
- 头像和昵称保存后同步更新当前端的顶部、侧栏及个人账户展示。
- 陪玩师的公开名片、作品和服务报价继续使用「资料与服务」中的审核流程；本次修改的是账号资料。
- 下线其他设备时，在对应设备卡片中输入当前密码确认。当前设备不显示下线按钮，可通过「退出登录」离开。
- 修改密码只填写一次当前密码。现有登录设备不会自动全部退出，需要时可在设备页逐个下线。
- 登录时账号、密码或登录端不匹配，统一提示「账号或密码错误」。账号停用、服务故障仍保留各自原因。

## 接口与存储

所有接口使用既有登录态，从服务端取得当前账号及终端，不接收用户 ID 或权限作为修改依据。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET / PATCH | `/api/auth/profile` | 读取、保存当前账号昵称和头像 |
| POST | `/api/auth/avatar-uploads` | 创建头像直传任务 |
| GET / DELETE | `/api/auth/avatar-uploads/{assetId}` | 查询状态、删除尚未使用的头像 |
| POST | `/api/auth/avatar-uploads/{assetId}/complete` | 完成上传和真实图片校验 |
| GET | `/api/auth/security/sessions` | 当前账号、当前终端最近 100 个有效会话 |
| POST | `/api/auth/security/verification` | 用当前密码申请一次性操作凭证 |
| POST | `/api/auth/security/change-password` | 使用凭证修改密码 |
| DELETE | `/api/auth/security/sessions/{sessionId}` | 使用凭证下线其他设备 |

资料更新字段为 `displayName`、可选 `avatarAssetId`、`removeAvatar`。昵称最长 32 个字符，空白表示恢复邮箱展示。保存操作使用账号行锁及版本条件，头像引用替换与资料修改在同一事务内完成。

头像复用现有 MinIO 预签名直传、上传摘要校验、最终对象封存和媒体引用管理。新用途为 `ACCOUNT_AVATAR`，不复用 `PROFILE_IMAGE`，避免账号头像等待尚未接入的内容审核器。它不能作为聊天图片、陪玩师公开展示图绕过原业务的用途和审核检查。

前端接受不超过 5 MiB 的 JPG、PNG、WebP，居中裁切并缩放到最大 512×512 的静态 PNG 后上传。服务端独立检查所有权、用途、大小、摘要、真实图片结构与尺寸；校验通过后为 `READY / NOT_REQUIRED`。不接收 SVG、HTML 或任意外部头像地址。头像读取使用短期签名地址，图片读取失败时回退文字头像。

资料更新只释放旧头像的账号引用，不删除其他业务的引用或直接删除 MinIO 对象。未保存的上传允许取消清理。

密码更新要求至少 8 个 Unicode 字符、最多 72 个 UTF-8 字节，不能等于邮箱或原密码。验证码凭证只存摘要，按账号、终端、操作类型和有效期原子消费。密码哈希计算在事务外完成，写入使用账号版本条件避免覆盖并发修改。

设备下线先完成外部会话清理，再标记数据库记录。清理失败时保留有效记录供重新验证后重试。不会把 Redis、实时连接清理或密码哈希计算包进数据库事务。

## 数据量与查询检查

| 表 | 每次访问规模 | 使用的索引/约束 |
| --- | --- | --- |
| `identity_user_account` | 当前账号 1 条 | 账号主键；更新同时检查版本 |
| `identity_login_session` | 当前端最多 100 条；单个下线目标 1 条 | `idx_identity_login_session_user_portal_active`、会话主键、指纹唯一约束 |
| `identity_step_up_verification` | 每次 1 个凭证 | 指纹唯一约束，附带账号、终端、操作和有效期条件 |
| `content_media_asset` | 每次处理 1 张新头像、至多 1 张旧头像 | 媒体主键、`uk_content_media_asset_object_key` |
| `content_media_reference` | 本账号的单条头像引用 | 资产、业务类型、业务 ID 的唯一约束 |
| `content_media_object_cleanup_task` | 复用上传及取消操作的固定数量任务 | 既有任务主键及去重约束 |

账号和媒体总量可以达到万条以上，以上请求仍按主键、唯一键或用户维度索引定位。数据库访问次数为 O(1)，不会随设备数量逐条查询。过期设备在循环外用一次 IN 更新；循环内只处理内存数据。没有新增全表读取、无界列表或 O(n²) 匹配。
